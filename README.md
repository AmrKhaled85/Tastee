# Tastee 🍔🥗🍕

Tastee is a modern and responsive food delivery web application built with React, TypeScript, and Tailwind CSS. It provides users with an intuitive platform to discover restaurants, browse food categories, search for meals, and enjoy a seamless ordering experience.

---

## ✨ Features

- Modern and responsive UI
- Interactive hero section with search functionality
- Browse food categories
- Popular restaurants showcase
- Restaurant cards with ratings and delivery information
- Promotional discount banner
- Mobile-friendly interface
- Smooth animations with Framer Motion
- Reusable React components
- Clean and scalable architecture
- Performance optimized

---

## 🛠 Tech Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- React Router DOM
- Swiper.js
- Lucide React
- React Icons

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/tastee.git
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

---

## 📦 Build for Production

```bash
npm run build
```
